## About Revision Room

**Revision Room** is a desktop learning application built to make studying more interactive, organized, and effective.

Whether you're studying from PDFs, trying to understand difficult concepts, preparing for exams, or testing your knowledge, Revision Room brings essential learning tools together in one place.

## Features

| Feature | Description |
|---|---|
| 📚 Study Materials | Upload and read PDF study materials. |
| 🤖 AI Explanations | Understand difficult topics with AI-powered explanations. |
| 📝 Question Generation | Generate MCQs, short-answer, and long-answer questions. |
| ⏱️ Test Room | Take timed tests and evaluate your knowledge. |
| 🏆 Rank Room | Compare your performance with other learners. |

## Download & Installation

1. Visit the [Latest Release](../../releases/latest).
2. Download the Windows `.exe` installer.
3. Run the downloaded installer.
4. Follow the installation instructions.
5. Open Revision Room and start learning!

> **Note:** Download the application only from this official repository or from the portfolio website.
